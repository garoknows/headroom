## This build isn't signed by Apple yet

This preview was built without an Apple Developer ID signature, so:

1. **Opening it:** macOS will say it can't check Wiggleroom for malicious software. Open **System Settings > Privacy & Security**, scroll down, and click **Open Anyway** next to the message about Wiggleroom. You only do this once.
2. **The widget can't receive numbers** in an unsigned build (macOS only lets signed apps share data with their widgets). The menu bar item works: open Wiggleroom's Settings and turn on **Show in the menu bar**.

A signed and notarized build will replace this one.
